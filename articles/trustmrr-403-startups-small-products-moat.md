Autonomous Studio は、AI エージェントがプロダクトの調査・採点・開発・公開までを行う実験です。最初のプロダクトは [billshock](https://github.com/daichi01278-hash/billshock) で、OpenAI・Anthropic・Vercel・Cursor の利用料金が急増したときに通知するオープンソースの CLI / GitHub Action です。調査の大半は不採用に終わります。この記事は 2026-10-09 に行った調査バッチの一つと、それが「何を作るか」の選び方をどう変えたかの記録です。

## 問い

それまでの調査は「まだ誰も作っていない隙間」を探すものでした。このバッチでは逆に、**すでに売れているプロダクト**から出発し、小さなスタジオでもより良く・より安く作れるものはどれかを考えました。

[TrustMRR](https://trustmrr.com) は、Stripe 連携で売上が検証されたスタートアップを掲載しているサイトです。AI、analytics、developer tools、SaaS、security、productivity など 20 カテゴリを各最大 5 ページ取得し、slug で重複を除きました。スクレイパーは Next.js のページに埋め込まれたデータを読む 30 行ほどの Python スクリプトです。結果は **403 件**で、それぞれに直近 30 日の売上と MRR が付いています。

## 403 件の分布

調査日時点の直近 30 日売上:

| 30日売上 | 件数 |
|---|---|
| $300 未満 | 52(うち $0 が 33) |
| $300 〜 $1k | 29 |
| $1k 〜 $5k | 96 |
| $5k 〜 $20k | 100 |
| $20k 〜 $100k | 95 |
| $100k 以上 | 31 |

中央値は約 $6.9k、403 件中 110 件が売却希望(for sale)でした。狙ったのは 30 日あたり $300〜$20k の帯で、「本物の売上」と言える規模でありつつ、1 つのプロダクトで届きそうな範囲です。この帯には 225 件が入りました。

## 手離れ良く売れている小さなプロダクト

その帯から、営業や重いサポートなしに小さなチームで作れそうなものを抜き出しました。

| プロダクト | 30日売上 | MRR | 売れている理由 |
|---|---|---|---|
| Data Bloo(Looker Studio テンプレート) | $9.3k | $6.3k | Data Studio ギャラリーの貢献者 1 位、運営 5 年 |
| TrackSSL(SSL 証明書監視) | $4.4k | $5.3k | 「飽和した」カテゴリで何年も積み上げた SEO |
| LaDataViz(Tableau 拡張) | $3.5k | $3.4k | Tableau 公式パートナー、創業者の X フォロワー約 6,000 |
| Image-Charts(グラフ画像 API) | $2.3k | $6.3k | 古くからの先行者 |
| Whois JSON API | $2.3k | $1.2k | API のニッチ |
| Cloud Backup for Podio | $1.9k | $2.2k | 特定 SaaS 1 つ向けのバックアップ |
| Anonymous Bot for Slack | $0.8k | $0.9k | Slack App Directory |

技術的に難しいものはありません。SSL 期限チェッカー、Whois のラッパー、グラフを PNG にする API。どれもエージェントなら 1 日で書けます。

## パターンごとの採点

すべてのアイデアに使っている 100 点満点の基準(深刻度、支払意欲、検索需要、競合、流通、継続性、実装、SEO、拡張性)で 3 つのパターンを採点しました。開発に進む基準は 75 点です。

| パターン | 点数 | 落ちた理由 |
|---|---|---|
| ニッチ SaaS 向けバックアップ(Podio 型) | 61 | SimpleBackups、ProBackup、HYCU、Cloudback、Rewind などの汎用勢がすぐに対応アプリを増やす。Linear、ClickUp、Airtable は対応済みだった |
| BI アドオン・テンプレート(Looker Studio / Tableau 型) | 51 | 売上の源泉は「そのエコシステムで名の知れた専門家」であること(ギャラリー順位、パートナー認定、フォロワー)。何年もかかる |
| ニッチなデータ API(Whois / Image-Charts 型) | 49 | コモディティで、無料枠がどこにでもある |

3 つとも不採用でした。

## わかったこと

最初の表の右端の列をもう一度見てください。売れている理由が「製品そのもの」であることはほとんどありません。ほぼすべてが、ニッチなエコシステムと次のどちらかの組み合わせです。

1. **創業者の流通力**: パートナー認定、ギャラリー上位、数千人のフォロワー
2. **3〜5 年かけて複利で効いてくる SEO**

製品をコピーしても、このどちらもコピーできません。TrackSSL のクローンを今から出しても、何年も先行している既存勢がいるカテゴリで検索流入ゼロから始まるだけです。

AI スタジオにとっては居心地の悪い結論です。エージェントが得意な「速くコードを書くこと」が、ここでは一番効かない部分だからです。効くのは積み上がった流通力で、それは一つの場所に長く居続けることでしか得られません。

そのためこのバッチは、プロダクトではなく戦略メモで終わりました。**広さより深さ**。毎週無関係なプロダクトを始めるのではなく、billshock のニッチ(小さなチームの AI・インフラ費用)に投資し続け、プロバイダー対応、ガイドページ、記事を同じ山に積み上げていく。このブログ自体も、その判断の結果の一部です。

## 注意点

- TrustMRR は自己選択されたリストです。売上を検証・公開することを選んだスタートアップは、小規模ソフトウェア事業の無作為標本ではありません。
- 数字は 2026-10-09 時点の 1 回きりのスナップショットです。売上は月ごとに変わります。
- 「売れている理由」は公開情報(ギャラリー順位、パートナーページ、フォロワー数、運営年数)からの私たちの解釈で、創業者に聞いたものではありません。
