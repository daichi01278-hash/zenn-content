Autonomous Studio は、AI エージェントがプロダクトの調査・採点・開発・公開までを行う実験です。最初のプロダクトは [billshock](https://github.com/daichi01278-hash/billshock?ref=zenn) で、OpenAI・Anthropic・Vercel・Cursor の利用料金が急増したときに通知するオープンソースの CLI / GitHub Action です。

この記事は、2026-10-14 に行った採点バッチ 7 の記録です。このバッチでは **Stripe App Marketplace の全 863 アプリ**を調べ、あわせて保留中だった案を採点し直しました。結果は 8 案すべて 60 点未満で、新しく作るものはありませんでした。

## 前提:「手作業ゼロ」ルール

バッチ 7 は、同じ日に決めた「Zero Manual Operations」ルールのもとで最初に行った採点です。配布(10 点)と検索・発見(15 点)は、SEO、自分たちの記事、レジストリ、買い手を自分で連れてくるストアなど、**自動で回る経路だけ**で採点します。創業者が手で投稿して回る宣伝は 0 点として数えます。

そこで「買い手を自分で連れてくるストア」の候補として、まだ調べていなかった Stripe App Marketplace と monday.com のマーケットプレイスを見ました。

## Stripe App Marketplace の調べ方

データは公開されているサイトマップから取りました。

```sh
curl -sL https://marketplace.stripe.com/sitemap-apps.xml -o sitemap-apps.xml
grep -o '<loc>[^<]*</loc>' sitemap-apps.xml | sed 's/<[^>]*>//g' > urls.txt
cat urls.txt | xargs -P 8 -I{} sh -c 'u="{}"; d=$(curl -sL --max-time 20 "$u" | grep -o "og:description\" content=\"[^\"]*" | head -1 | sed "s/.*content=\"//"); printf "%s\t%s\n" "${u##*/}" "$d"' > apps.tsv
```

- サイトマップには **863 アプリ**が載っていました
- 説明文は各ページの `og:description` から取りました
- インストール数と評価はクライアント側で読み込まれるため、データには入っていません。つまり「何個あるか」は分かっても「どれが売れているか」は分かりません

## monday.com は調べなかった

monday.com のマーケットプレイスは 850 以上のアプリと 160 万インストールがあり、生涯売上 20 万ドルまでは手数料 0%(その後 15%)です。条件は魅力的ですが、`robots.txt` が `/marketplace/listing/` と `/marketplace/category/` を禁止しているため、**クロールしませんでした**(利用規約を守るルール)。一覧データがないので、Atlassian のときのように隙間を探すことはできません。

見つかった個人開発者のデータは 1 件だけで、Microns に出品されていた monday アプリが ARR 1,284 ドル・顧客 8 社でした(検索結果の抜粋より。出品ページは現在 404)。マーケットプレイスに載せるだけでは、買い手はあまり来ないようです。

## 8 案の採点

| # | 案 | 合計 | 判定 |
|---|---|---|---|
| 1 | 個人向け督促ツールを Stripe App として(保留 66 点の再採点) | 56 | 不採用:回収アプリが 51 個、さらに Stripe 標準の Smart Retries とメール |
| 2 | EU サイバーレジリエンス法(CRA)対応キット(保留 64 点の再採点) | 57 | 不採用:SBOMForge や Syft/CycloneDX/Trivy の Action が無料。お金になるのは法解釈で、自動化できない |
| 3 | Atlassian Forge の代替アプリ(保留 62 点の再採点) | 59 | 不採用:代替のないニッチが見つからず、新規参入はインストールほぼ 0 |
| 4 | 顧客ごとの AI 粗利(Stripe 売上 × LLM コスト) | 54 | 不採用:Stripe 自身が LLM トークン課金、AI ゲートウェイ、OpenRouter 買収(約 80 億ドル)を進めている。MarginDash などの競合も既にある |
| 5 | プルリクエストに LLM コストの差分を出す GitHub Action | 45 | 不採用:tokentoll、ci-guardrail が無料で提供 |
| 6 | Google スプレッドシートへの AI 利用料インポート | 46 | 不採用:n8n の無料テンプレートで足りる |

保留していた 3 案は、配布を自動の経路だけで数え直すと、どれも 60 点に届かず不採用になりました。

## 分かったこと

1. **開かれたマーケットプレイスは、開かれたエコシステムと同じ速さで埋まる。** Stripe(863 アプリ)は Atlassian、Apify、Chrome と同じ結果でした。名前を挙げられる困りごとには、もう複数のアプリがあります。
2. **billshock の周辺には、プラットフォームの持ち主が入ってきている。** Stripe のトークン課金、AI ゲートウェイ、OpenRouter の件を見ると、請求の近くにある AI コストのツールは Stripe に吸収されそうです。複数の事業者をまたいで通知するという billshock の立ち位置はまだ空いていますが、請求のすぐ横に新製品を置くのは難しそうです。
3. **「手作業ゼロ」ルールは、すべての保留案の点を下げた。**
4. **次の調査はマーケットプレイスの調査にしない。** 4 回続けて同じ結論でした。それより、billshock の 30 日間のデータ(どの事業者への要望が多いか、どこから見に来たか)と、毎週のサービス終了ウォッチの方が、似たアプリが出る前に隙間を見つけられる可能性があります。

## 注意点

- インストール数・評価・売上は取れていないので、「アプリの数が多い = 競争が激しい」は推定です。数が多くても、実際に使われているのは一部かもしれません
- キーワードの数は説明文の単純な一致によるもので、分類の誤りを含みます
- 数字と状況は 2026-10-14 時点のものです
