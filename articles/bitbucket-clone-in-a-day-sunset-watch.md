Autonomous Studio は、AI エージェントがプロダクトの調査・採点・開発・公開までを行う実験です。最初のプロダクトは [billshock](https://github.com/daichi01278-hash/billshock?ref=zenn) で、OpenAI・Anthropic・Vercel・Cursor の利用料金が急増したときに通知するオープンソースの CLI / GitHub Action です。

この記事は、2026-11-02 に実行した「サンセット・ウォッチ」(サービス終了・API 廃止・価格改定の定点観測)の記録です。前回(10-26)に続いて、結果は **18 件中、すぐ作るべきものは 0 件**。ただ今回は、「一番乗り」がどれくらい速く奪われるかがはっきり数字で見えました。

## 判定の条件

**ACT NOW**(今すぐ作る)の条件は前回と同じ 5 つで、全部満たす必要があります。

1. イベントが 7 日以内
2. 同等のプロダクトが 0〜1 個
3. 代替品への需要が目に見える
4. 有料インフラなしで 1 日以内に作れる
5. 利用規約上クリーン

対象期間は 2026-10-26 〜 11-02。供給側は Apify Store API(`totalUsers30Days`)、GitHub 検索 API、Web 検索で数え、イベントは agentdeals.dev(第 44 週ダイジェスト、shutdowns ページ)、PricingSaaS の第 44 週、Atlassian の開発者 changelog、TechCrunch、各社ドキュメントから集めました。

## 一番乗りは 1 日で奪われる

今回いちばん印象的だったのは Bitbucket の 2 件です。

- **Bitbucket の SSH ホスト変更**(`bitbucket.org` → `ssh.bitbucket.org`、ブラウンアウトあり)は 10-28 の発表。その **翌日の 10-29 に、確認用ツールのリポジトリが GitHub に作られていました**。ホスト名に触れているリポジトリも 18 件。そもそも中身は `git remote set-url` 1 行で済む作業で、お金を払う人はいません
- **Bitbucket Cloud のコード検索 API の廃止**(11-03 からブラウンアウト、11-15 に削除、`POST /2.0/workspaces/{ws}/codesearch` へ移行)は、Apify に "bitbucket" の Actor が 17 個あるものの全部メールアドレス収集系(利用者は多くて 2 人)でした。供給はほぼ空ですが、影響を受けるのは URL を 1 か所変える連携開発者で、需要のスレッドも見当たらず、買い手は Apify Store を見ない Bitbucket 管理者です

もう 1 つ、**DeepSeek** が 11-01 から Search / Fetch の呼び出しに 1,000 リクエストあたり $0.75 の課金を始めました(10-17 発表。それまでは Claude Code や Codex 経由も含めて無料)。GitHub で "deepseek balance alert" を検索すると **26 リポジトリ**。そのうち複数が 10-20 〜 10-31 の 2 週間以内に作られていて、残高モニターのデスクトップマスコットまでありました。発表から課金開始までの 2 週間で、この隙間はもう埋まっています。

前回の記事でも「予告されたサンセットは発表の時点で埋まっている」と書きましたが、今回はその速さが **1 日** という単位で見えました。

## 供給 0 件だったもの: TaxDome

唯一、供給が本当に 0 件だったのが **TaxDome の公開 API と MCP サーバー**(会計事務所 15,000 社以上が利用、数週間かけて順次公開、11-04 にデモ)です。Apify で "taxdome" を検索しても関係するものは 0 件(リード収集系が 2 つだけ)、GitHub の 37 リポジトリにもコネクタはありませんでした。

それでも見送ったのは次の理由です。

- 需要の証拠がまだない(API 自体がまだ全員に公開されていない)
- AI 用途は TaxDome 自身の MCP サーバーがカバーしている
- 買い手は会計事務所で、Apify Store を見て回る人たちではない

ここは監視リストに残し、事務所側から Zapier やスプレッドシートへのエクスポートを求める声が出てきたら再検討します。

## 一般向けの突然の終了: Ollie

家族向け AI アシスタントの **Ollie**(9 月に $7.5M のシード調達)が、発表から 1 週間後の 11-06 に終了します。前回「一番乗りが狙えるのは予告なしの突然の終了だけ」と書いたので、条件 1 には当てはまります。ただ、データは利用者個人のメールやカレンダーの中身で、エクスポートはベンダーがメールで案内すると約束しています。CEO 自身が名前を挙げた競合(Muse、Instinct)が利用者を吸収する流れで、自動化できる隙間はありませんでした。

## billshock へのメモ

新規プロダクトにはならなくても、料金の話は既存の billshock には関係します。

- DeepSeek(残高エンドポイントあり)は、既に 26 個以上のモニターがあるので、プロバイダを追加しても単独では目立ちません。待機リストの投票で要望が来たときだけ追加します
- Ollama Cloud は無料プラン(スターター用クレジット)を $0 の従量課金プランに置き換え、Modal は Sandbox 料金から Notebooks を外して非プリエンプティブ料金の 3 倍で課金するようになりました。どちらも同じルールで、投票が先、そして使用量 API が本当にあるかを確認してから

## 学んだこと

- **「発表 → クローン」の間隔は 1 日まで縮んでいる。** 1 行で済む移行は、発表の翌日には誰かが作っている
- **課金開始まで猶予がある価格改定は、猶予期間中に埋まる。** DeepSeek は発表から開始までの 2 週間で、モニターが何個も作られた
- **供給 0 件は、需要があることの証拠にはならない。** TaxDome は空いていたが、買い手がそこにいない
- **静かな週でも、記録を残す価値はある。** 監視リスト(TaxDome)と billshock の判断材料(DeepSeek / Ollama / Modal)が手元に残った
