## バイク維持費を選んだ理由

需要の証拠は Google の検索候補です。`experiments/batch8-scan/suggest.py` で取得しました。

- 「バイク 維持費」→ 年間 / 250 / 400 / 排気量別 / 比較 / 125 / 月 / 中型
- 「バイク 車検 費用」→ 400cc / 大型 / ユーザー / 1000cc
- 「バイク 売る タイミング」→ 車検 / 税金
- 「バイク 税金 4月1日」→ 登録 / 廃車

ただし、検索候補に出ることは「ある程度は検索されている」ことしか意味しません。有料ツールを契約していないので、**検索ボリュームは分かりません**。

検索結果の上位は、比較サイトや買取サイト、バイクメディアの**記事**でした。車種や年式を入れて計算できる二輪専用の日本語ツールは見つかりませんでした。ただし調べたのは数クエリだけなので、「存在しない」とまでは言えません。

差別化の材料は時期です。自賠責保険料は 2026-11-01 以降に始まる契約から改定され、二輪・原付は 10% を超える値上げになります。

## 原本確認で見つかった2つの誤り

MVP の時点では、料金表の一部は二次情報のままで、`data.mjs` のコメントに `status: single`(出典が1つだけ)と書いていました。公開前にすべての料金を一次資料で確認し直したところ、誤りが2つ見つかりました。

### 1. 車検の検査手数料: 1,800円 → 2,100円

仮に置いていた 1,800円は推定値でした。国交省の自動車登録ポータル「登録・検査手数料一覧表」(令和8年4月1日現在)では、小型自動車(二輪)の持込検査は 2,100円(印紙600円+証紙1,500円)です。お店経由で保安基準適合証を出す場合は 1,500円です。

### 2. 「13年経過」は13年ちょうどではない

重量税(小型二輪・自家用・2年)は 3,800円、13年経過で 4,600円、18年経過で 5,000円です。この金額は広く出回っている数字と同じでした。違っていたのは**どの時点から上がるか**です。

国交省の資料(令和8年度税制改正に伴う自動車重量税の税額の基本的な考え方)によると、「13年経過」は初度検査年月から **12年10か月以後** の検査に適用されます。18年経過も同じで、17年10か月以後です。

最初の実装は「今日の時点で何年たったか」を年単位で数え、13以上かどうかで判定していました。修正後は、**検査を受ける月**までの経過月数で判定しています。

```js
// 国交省の基準では12年10か月以後が「13年経過」、17年10か月以後が「18年経過」。
export function weightTax2y(elapsedMonths) {
  const w = RATES.weightTaxKogata2y;
  if (elapsedMonths >= 17 * 12 + 10) return w.from18;
  if (elapsedMonths >= 12 * 12 + 10) return w.from13;
  return w.base;
}
```

「もうすぐ重量税が上がります」という案内も、この境目に合わせて直しました。

自賠責の新料金(24か月、離島以外・沖縄県を除く)は、損害保険料率算出機構の基準料率表(2026-04-30 届出)で確かめました。原付 9,630円、軽二輪 9,780円、小型二輪 9,640円です。軽二輪の 9,780円は、二次情報では1つの出典にしか載っていませんでしたが、原本と一致しました。現行料金は二次情報どうしで数字が食い違っていたため、計算には新料金だけを使っています。

計算機のような小さなサイトでは、ロジックより料金表のほうが誤りやすいと分かりました。境界条件の定義も料金表の一部として扱う必要があります。

## 収益化の見積もり(すべて仮定)

収益はバイク買取のアフィリエイトを想定しています。A8.net の管理画面で確認した数字は次のとおりです。

| プログラム | 成果報酬 | EPC |
|---|---|---|
| バイク館イエローハット(採用・提携申請中) | 新規査定申込 3,500円 | 65.11円 |
| バイクBOON(予備) | 査定申込 4,000円 | 48.88円 |

EPC は、A8 が表示している1クリックあたりの平均報酬です。EPC 65.11円で月5万円を得るには、月に約770クリックが必要です。結果欄のリンクのクリック率を5%と仮定すると、月に約1.5万訪問になります。どの数字も、このサイトで実際に測ったものではありません。

リンクは提携が承認されてから、中型以上(126cc〜)の結果欄にテキストリンクを1つだけ置く予定です。
