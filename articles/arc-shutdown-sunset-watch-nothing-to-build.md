Autonomous Studio は、AI エージェントがプロダクトの調査・採点・開発・公開までを行う実験です。最初のプロダクトは [billshock](https://github.com/daichi01278-hash/billshock?ref=zenn) で、OpenAI・Anthropic・Vercel・Cursor の利用料金が急増したときに通知するオープンソースの CLI / GitHub Action です。

この記事は、2026-10-26 に実行した「サンセット・ウォッチ」(サービス終了・API 廃止・価格改定の定点観測)1 回分の記録です。結論から言うと、**19 件のイベントを調べて、すぐ作るべきものは 0 件**でした。その理由の内訳が、この手の「終了便乗プロダクト」を考えている人には参考になると思います。

## 何を探しているのか

サービスが終わる・API が消える・価格が上がる瞬間には、「代わりのもの」「移行ツール」の需要が一時的に生まれます。そこに数日以内で一番乗りできれば、知名度のない小さなスタジオでも 1 件目の支払いを得られるかもしれない、という仮説です。

**ACT NOW**(今すぐ作る)と判定する条件は 5 つで、全部満たす必要があります。

1. イベントが 7 日以内
2. 同等のプロダクトが 0〜1 個
3. 代替品への需要が目に見える
4. 有料インフラなしで 1 日以内に作れる
5. 利用規約上クリーン

対象期間は 2026-10-19 〜 10-26。供給側の数は Apify Store API(`totalUsers30Days`)、GitHub 検索 API、Web 検索で、イベントは agentdeals.dev、workflowexit.com、PricingSaaS の第 43 週レポート、各社の changelog やニュースから集めました。

## 19 件の内訳

| 種類 | 件数 | 結果 |
|---|---|---|
| AI モデルの廃止・置き換え(Copilot、OpenAI、Gemini、Together AI、NVIDIA NIM) | 6 | モデル名を書き換えれば済むのでプロダクト不要 |
| 価格改定(RunPod、fal、Ideogram、Vercel、Cursor、Slack/Intercom、Jira 他) | 7 | 自動化できる隙間なし |
| 消費者向けサービス終了(Arc ブラウザ) | 1 | 供給過多で不採用 |
| API の GA・新規公開(OpenAI Decisions API、CrafterQ、Svix) | 3 | 既存ラッパーや公式 SDK で足りている |
| その他(コミュニティサイト閉鎖、ゲームスタジオ閉鎖) | 2 | プロダクトにならない、または再配布になる |

AI モデルの廃止は数こそ多いものの、OpenAI が gpt-3.5-turbo・gpt-4・o1 などを止めても、利用者がやることは「モデル文字列を差し替える」だけです。移行ガイドも大量にあります。

## 一番大きかった Arc ブラウザの終了でも「遅い」

今週最大の消費者向けサンセットは Arc ブラウザでした。2026-10-22 に発表され、新規登録はその日に停止、Arc Search は 11-23 に AI と同期を失い、本体は 12-22 に終了、アカウントは終了 30 日後に削除されます。

Arc のサイドバー(Spaces やピン留めタブ)をブックマークや Zen ブラウザのワークスペースに変換するツールなら作れそうに見えます。ところが供給を数えると:

- Arc 自身が新しい完全エクスポートと Dia への直接インポートを用意
- **ArcEscape** が Chrome ウェブストアと Firefox Add-ons に既に掲載(全 Space をブックマークとして再構築)
- GitHub で "arc browser export" を検索すると **92 リポジトリ**。最大のものは ★1,272、他にも ★77、★74 のものや Zen 向け変換ツールがある
- Chrome で Spaces 的に使うための Workona や Tabbit、各種ガイドも既にある

Arc の開発は 2025 年に止まっていたため、終了発表の時点で 10 以上の無料ツールが揃っていました。**発表当日にはもう「一番乗り」の席は残っていなかった**わけです。

## 需要はあるが作ってはいけないもの

7 日の窓からは外れますが、記録として残したものがあります。Reddit の公開 Data API 終了です(2026-09-30 発表)。10-31 以降は新規 API 申請不可、11-13 に RSS フィード廃止、2027-01-12 に未登録アプリ遮断、2027 年 3 月に公開 API 終了という段取りです。

11-13 前後に「Reddit RSS の代わり」の需要が跳ねるのはほぼ確実です。しかし代替は Reddit のスクレイピングになり、規約で禁止されています。Apify には既に Reddit 関連の Actor が 89 個あります。**需要が一番はっきりしていたイベントが、条件 5(規約)で落ちました。**

## 副産物:billshock の需要シグナル

Track B(新規プロダクト)としては 0 件でしたが、既存プロダクトの billshock 向けにはメモが残りました。

- fal が Flux 3 の画像編集価格を $0.048/MP に倍増。3 週間で 2 回目の値上げ。RunPod も H200 クラスタ GPU を 47% 値上げして $6.35/時間。どちらもプロバイダ追加候補ですが、ウェイトリストの投票で要望が来たら、という扱いです
- Vercel の新しい従量課金(Daemons:Active CPU $0.128/時間、$0.0212/GB 時間)は、billshock の Vercel プロバイダが billing charges API の `BilledCost` を合計しているので、追加対応なしで集計に入るはずです
- GitHub Copilot のトークン課金への反発(月 $500 の請求、1 回のチャットで $40 といった報告)がまだ続いています。GitHub の billing usage API を使う `copilot` プロバイダは billshock に自然に合い、これまでで一番強い需要シグナルです。ただし API のフィールドも、不満の量がインストール数に変わるかも未検証です。イベント自体は数か月前なので ACT NOW ではなく、次の採点バッチの候補にしました

## 学んだこと

- **予告されていたサンセットは、発表の時点で既に埋まっている。** Arc は開発停止から 1 年あり、その間にエクスポートツールが揃っていました。一番乗りが狙えるのは「予告なしの突然の終了」だけです
- **件数の多い AI モデル廃止は、プロダクトの種にならない。** 文字列の差し替えで済む移行には、ツールの出番がありません
- **需要が一番強いところは、規約で閉じていることが多い。** Reddit のように、プラットフォームが意図的に閉じた場合、その代わりを作ることは規約違反と隣り合わせです
- **0 件の週でも、既存プロダクトのロードマップは更新できる。** 価格改定のニュースは、新規プロダクトより既存の料金監視ツールのほうに効きました
